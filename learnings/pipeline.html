  3. 02
    Script writing
    /script-writer

    Turns a topic + research into a TTS-ready script in the house style (170 wpm, short declaratives, "But" pivots, three-part lists, concrete numbers). Encodes a voice, not a recipe. Mandatory cold open: the opening line IS the hook (claim / number / question / scene) landing in ~10s (~25–30 words) — never a frame-setting ramp. Reset cadence: no single idea runs past ~45–60s without a reset. Hook is carved last from the strongest body beat. Long-form stays CTA-free. Also scaffolds the video folder and runs npx hyperframes init.

  4. 3a
    Voiceover + transcript · record your voice // default
    /transcribe-and-plan-cuts

    Drop your recording at audio/raw.mp3. The skill transcribes it (Scribe v2), dispatches the audio-cut-decider agent to plan first-pass cuts, and hands you the tools/audio-editor URL to refine and save. Two paths exist for Stage 3; recording is the default — TTS (3b) below.

    Produces
    • audio/raw.mp3 (user-recorded)
    • transcript.json
    • cuts.json
    The full 3a chain

    raw.mp3 → Scribe v2 transcript.json + cuts.json → refine cuts in tools/audio-editor (bun dev on :5173, open /#/edit/<slug>-<date>, Save cuts) → manual ffmpeg concat renders audio/voiceover.mp3 → re-transcribe the cut audio so transcript.json timings match the final cut.

    3a does not flow straight to composition — a cuts edit, a manual ffmpeg render, and a re-transcription sit between recording and Stage 4. The pre-cut transcript no longer aligns once cuts are applied.
    Re-running clobbers cuts.json and destroys editor saves. The cost checkpoint surfaces this — heed the warning. The skill never modifies audio/raw.mp3 (source of truth).
    Audio events ([cough], [breath], [mouth_noise]) are first-class — the cut-decider needs them.

  9. 07
    Preview + lint iteration
    hyperframes preview / lint

    Scrub the timeline, watch each scene at its hold frame. Inspect at t=mid, not t=0 — entrances haven't landed at 0. video-director runs this loop continuously; it's broken out here because it's where shippable-looking bugs get caught.

    If lint warns about something that "looks fine in preview," fix the lint finding anyway. Those have caught shippable-looking bugs.

SFX: the editorial brain + two deterministic tools

Sound effects are scored inside video-director as Step H — there is no standalone /sfx-author skill anymore (it was folded in and removed in 2026-06). The pass runs per scene, right after that scene's visual QA, and reconciles the whole video at the end. Around the editorial brain sit two Python CLIs: one builds a metadata catalog of the SFX library; the other deterministically picks files and emits the audio sub-composition.

Then the music bed (stage 8): a separate pass that lays a human-curated bed underneath the locked VO + SFX. Master loudness normalization to −14 LUFS / −1 dBTP is a later concern.

Captions, description, and the publish-time gate

The publishing surface is shaped by one hard constraint: the youtube-studio MCP is v1. It can read analytics and write title / description / tags / thumbnail — but it cannot upload a video, schedule a publish, or write captions. So upload is a manual Studio step, captions are a detect-and-hand-off, and the skills here either prep artifacts for that manual upload or QA the live result afterward.

Order: captions + description are prepped while the composition renders; you upload by hand; then /video-publish-qa is the final gate before the video indexes publicly.

    Captions — progressive discovery
    /create-srt-and-translate

It then offers the follow-up. Phase 2 (on-demand only) translates into the 13 YouTube auto-dub languages, reading the existing captions.srt as source.

    Phase 2 triggers (explicit only)
    • translate the captions
    • translate to all languages
    • do the localization
    • dub it
    • prep for multi-language upload
    Produces
    • captions.srt (English — Phase 1)
    • multi-lingual/srt/{ar,de,es,fr,hi,id,it,ja,pl,pt,ru,tr,vi}.srt (Phase 2)
    Plain requests ("create the SRT", "make the captions") are Phase 1 only — never roll into translations without an explicit trigger.
    The MCP can't write captions — hand off the manual path: Studio → Subtitles → Add language → English → Upload file → With timing. English captions also unlock auto-translate and the Hindi auto-dub.

Long-form → ~5 vertical Shorts that funnel back

/shorts-creator turns a finished long-form video into ~5 (up to 10) vertical 1080×1920 Shorts, each ending on a Cleo-Abram-style subscribe CTA. This is the channel's strongest discovery path — a companion Short pulled 2.7× the flagship's views. Like video-director it's an orchestrator: it owns beat selection, the Shorts script shape, and the publish hand-off, and delegates voiceover → portrait composition → vertical cover → render to the existing skills. Portrait is a layout delta on video-director, not a second engine.

Two phases, both gated: Phase 1 selects beats + drafts scripts + a stagger plan for review; Phase 2 builds one approved Short at a time. Publishing stays a manual Studio hand-off (MCP v1 can't upload or schedule).

Draft each clip's script in the Shorts shape (below). Draft a stagger plan — one Short every ~3 days. Write shorts/PLAN.md + each Short's script.md, then stop and present the plan.

Failure smells
  • design.md is over 60 lines
  • .hyperframes/expanded-prompt.md exists and is over 100 lines
  • compositions/ contains files marked PLACEHOLDER or [ TO BE BUILT ]
  • The Scene 1 thumbnail is a CSS primitive, not a real-looking artifact
  • The session is on turn 7+ and Scene 1 isn't built yet
  • An intermediate spec file cites a project rule then violates it
  • A subtopic runs past ~60s with no reset (pivot / frame change / closed loop)
  • The cold open is a frame-setting ramp, not a hook in the first ~10s
Rules going forward
01

Keep design.md ≤ ~50 lines

Palette · typography · motion · 5–6 don'ts. Not: atmosphere-layer recipes, transition tables, component formulas. Add those only after the third video proves you keep reaching for the same primitive — premature abstraction otherwise.

02

Skip expanded-prompt.md by default

Heavy scaffolding that pre-decides every scene's depth layers, verbs, and transitions. Use only when runtime is 6+ minutes and beats genuinely need explicit per-scene timing locks and you'll treat the expansion as a constraint envelope (palette + anchor timings + transition out), not a scene script.

03

Multi-composition split is fine — but build every scene

Pre-scaffolding compositions/scene-01.html…scene-11.html is neutral on creativity but creates a coordination tax. Either build all scenes in one session, or single-file composition for short videos (≤2–3 min). Don't end with placeholder stubs.

04

The first scene sets the quality bar

Generic CSS checkbox in scene 1 → generic CSS everything-else. Real-looking reCAPTCHA in scene 1 → the model carries that worldbuilding forward. When invoking /video-director, point at a known-good reference video as the explicit quality bar.

05

First-message specificity matters

"What's next?" lets the skill machinery default to its heaviest path. Specificity anchors a small, concrete first step and lets the build grow iteratively. The first message should name one concrete artifact, not ask for direction.

06

Cold open in ~10s; reset every ~45–60s

The script-level retention floor (the fix for the flagship's 0:42 drop-off and 4:49 drag). The opening line IS the hook — claim / number / question / scene in the first ~25–30 words, never a ramp. No single idea runs past ~45–60s without a reset (pivot conjunction / frame change / pattern interrupt / closed loop). Both rules are corpus-grounded in docs/creator-patterns.md, which is a menu, not a checklist.

07

Pipeline-emitted artifacts respect project CLAUDE.md

Every intermediate artifact (design.md, per-scene spec) has to pass the same project rules the final composition does. The captchas expanded-prompt.md cited the no-chrome rule, then prescribed editorial chrome in beat 1. A meta-check at the end of any spec-generating step catches this.
