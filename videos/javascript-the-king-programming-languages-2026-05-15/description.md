In 2014, a programmer called JavaScript an "awful language" that had escaped the browser. Today it runs your servers, your apps, and even the Windows Start menu.

JavaScript was written in ten days as a marketing gimmick — a browser scripting language built to ride the coattails of Java. It was never the most loved programming language, and for fourteen years it never left the web. This is the story of how it escaped: how Node.js put JavaScript on the server, how Electron and React Native carried it onto desktop and mobile, and how it ended up drawing the Start menu of Windows itself. JavaScript didn't win on quality. It won on supply — and this video traces exactly how.
