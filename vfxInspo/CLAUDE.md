# vfxInspo — instructions

A flat folder of VFX style reference frames. Filenames are the search index.

## Looking for inspiration

1. Read `README.md` first — it has a one-line technique note per frame. Match the
   note to the scene you're authoring before opening any PNG.
2. If a note looks right, then open that single PNG to study the look. Don't
   vision-parse every image — the filenames and README exist so you don't have to.

## Adding a new inspiration

1. Name the file descriptively, kebab-case, technique-first
   (e.g. `glitch-scanline-wipe-on-dark-terminal.png`), so it's findable by name alone.
2. Add a matching bullet to `README.md` under **Frames**: bold filename, then 2-3
   lines describing the technique and a "Good for:" line of use cases.
3. Keep README order and filenames in sync — every PNG has exactly one README entry.
