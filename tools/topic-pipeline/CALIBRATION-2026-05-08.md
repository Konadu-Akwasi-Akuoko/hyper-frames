## Method

- Source list: `data/inbox.json`, top 20 + bottom 20 by v1 composite
  (`best_composite`).
- Cold-search data: yt-dlp `ytsearch5:` per strategic candidate, archived
  at `data/cold-search/2026-05-08/*.txt`. 10 candidates measured directly.
  The remaining 30 use estimated medians based on topic class (universal
  consumer / dev-curiosity / build-log / news).
- Tier B reference-channel hit: estimated from prior knowledge of recent
  Pawel / Veritasium / Cleo Abram / Tom Scott / Computerphile / rabbithole
  / CodeAesthetic / Branch Education / Welch Labs / LearnThatStack /
  CodeSource / TheCodingGopher catalogues. Marked `?` where uncertain;
  treated as 0 (no hit) when uncertain.
- Autocomplete: estimated from whether the natural curious-question form
  is something a layperson would actually type. Will be machine-checked
  when #109 lands.
- Best-angle generated by hand for 16 candidates the LLM phase silently
  skipped (this exposes a serious v1 bug — see "Bug surfaced" below).
- v2 composite: 6 axes × 0–20 = 0–120 → divided by 1.2 for /100 display.

## Open issues exposed by this calibration

- **AI-slop / Kurzgesagt unlisted**: Kurzgesagt is a near-perfect
  reference channel (curiosity + production, regularly covers computing).
  Strong candidate for Tier B promotion. Add to RUBRIC.md? Not in current
  list of 12.
- **Demand inflation risk**: Pix and AI-slop both score >70 partly
  because cold-search median views are huge for adjacent (not exact-angle)
  videos. Consider tightening the cold-search definition to "videos that
  match the *intended angle*, not the topic broadly." Easy fix: when
  computing the median, weight only top-3 results that the LLM judges as
  *same-angle*. Adds an LLM call per candidate but it's already there for
  hook scoring.
- **Aggregator-breadth cap may be too low**: WEI scored 2/4 (HN+Reddit)
  in this calibration. With a richer source set (Lobsters/daily.dev
  presence) it would saturate at 4/4. The cap feels well-tuned — no change.
- **Tier B coverage data is missing**: I treated all Tier B hits as 0
  unless I had specific knowledge. Once #106 lands (channel feed module),
  the demand sub-axis 1 will firm up considerably. The current calibration
  is a *floor* on v2 scores — real Tier B hits will only push curiosity
  candidates higher.
